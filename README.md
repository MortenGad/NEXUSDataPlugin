# NEXUS Data plugin for Claude Code

Danish company data from the NEXUS Data API as tools in Claude Code: CVR register records, segment search, board and management, production units, annual-report financials, company summaries and news & developments.

You need a NEXUS API key to use it. Ask your NEXUS contact at itm8.

```
/plugin marketplace add MortenGad/NEXUSDataPlugin
/plugin install nexus-data@nexus
```

Setup and troubleshooting are in [plugins/nexus-data/README.md](plugins/nexus-data/README.md).
